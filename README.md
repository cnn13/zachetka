# Зачётка

Сайт для совместной подготовки к сессии: архив лекций, билеты, помодоро-таймер.
Написан на Python и Django, внешний вид на Bootstrap.

## Кто за какую папку отвечает

## Роли в команде

| Роль | Что делает | Где работает |
|---|---|---|
| Проджект-менеджер | План спринтов, доска YouGile, отчёты, проверка и слияние pull request'ов | YouGile, `config/`, ветка `main` |
| Аналитик | Описывает задачи в YouGile (что сделать и как проверить), макеты страниц, сбор материалов у старост, инструкция пользователя | YouGile, `README.md` |
| Бэкенд-разработчик | Модели, логика, адреса страниц, админка, загрузка файлов, подсчёт процентов, рейтинга и стриков | `models.py`, `views.py`, `urls.py`, `admin.py` во всех приложениях |
| Фронтенд-разработчик | Внешний вид страниц на Bootstrap, формы, таймер и графики на JavaScript | `templates/`, `*/templates/`, `static/` |
| Тестировщик | Проверяет сайт по сценариям, заводит ошибки в YouGile, пишет простые автотесты | `tests.py` во всех приложениях |

## Разделы сайта

| Папка | Раздел |
|---|---|
| `materials/` | Архив лекций и конспектов |
| `tickets/` | Билеты, чек-лист, случайный билет |

| `templates/base.html` | Общий шаблон и меню |

## Как бэкенд и фронтенд работают вместе

1. Бэкенд делает модель, view и адрес страницы, а в карточке YouGile пишет,
   какие данные передаёт в шаблон, например: `materials` — список материалов.
2. Фронтенд верстает шаблон страницы и выводит эти данные.
3. Пока бэкенд не готов, фронтенд верстает страницу с данными-примерами,
   написанными прямо в HTML, а потом заменяет их на настоящие.

Работайте в своей папке. Если нужно поменять чужую — сначала напишите её хозяину.

## Как запустить проект у себя (один раз)

Нужны **Python 3.10 или новее** и **Git**.
При установке Python на Windows поставьте галочку «Add Python to PATH».

Откройте терминал (на Windows — «Командная строка» или терминал в VS Code) и выполните по очереди:

```bash
# 1. Скачать проект
git clone https://github.com/cnn13/zachetka.git
cd zachetka

# 2. Создать виртуальное окружение — отдельную «коробку» для библиотек проекта
python -m venv venv

# 3. Включить его
venv\Scripts\activate          # Windows
 **Windows: ошибка «выполнение сценариев отключено в этой системе»?**
 Выполните один раз: `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`,
ответьте `Y` и снова запустите `venv\Scripts\activate`.
source venv/bin/activate       # macOS и Linux

# 4. Установить Django
pip install -r requirements.txt

# 5. Создать базу данных
python manage.py migrate

# 6. Создать себе администратора (придумайте логин и пароль, email можно пропустить)
python manage.py createsuperuser

# 7. Запустить сайт
python manage.py runserver
```

Откройте в браузере:

- http://127.0.0.1:8000/ — сайт
- http://127.0.0.1:8000/admin/ — админка (вход под администратором из шага 6)

Остановить сайт — `Ctrl + C` в терминале.

## Как запускать в следующие разы

```bash
cd zachetka
venv\Scripts\activate          # или source venv/bin/activate
git pull                       # забрать изменения команды
python manage.py migrate       # если кто-то добавил новые модели
python manage.py runserver
```

## Как сдавать свою задачу

1. Перед началом работы заберите свежую версию: `git pull`.
2. Создайте ветку под задачу: `git checkout -b 1.4-material-model`
   (номер и короткое название задачи из YouGile).
3. Сделайте задачу и проверьте, что сайт запускается.
4. Сохраните и отправьте:
   ```bash
   git add .
   git commit -m "1.4 Модель Material в админке"
   git push -u origin 1.4-material-model
   ```
5. На GitHub нажмите **Compare & pull request**. Наставник посмотрит код и вольёт его в общий проект.
6. Перенесите карточку в YouGile в колонку «На проверке».

## Если что-то не работает

- Сначала прочитайте последнюю строку ошибки в терминале — там обычно написано, что не так.
- Добавили или изменили модель? Выполните `python manage.py makemigrations`, затем `python manage.py migrate`.
- **Правило 30 минут:** не получается больше 30 минут — пишите в общий чат: что делали, какую ошибку видите (скриншот или текст).
