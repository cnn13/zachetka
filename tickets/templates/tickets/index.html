Простыми словами:

Предел функции — это число, к которому стремится значение функции f(x), когда аргумент x подбирается сколь угодно близко к заданной точке c.

Строгое определение по Коши (на языке эпсилон - дельта):

Число L называется пределом функции, если для любого расстояния ε > 0 найдется такое расстояние δ > 0, что как только аргумент попадает в интервал:

0 < |x - c| < δ

значение самой функции гарантированно попадает в интервал:

|f(x) - L| < ε

Суть теоремы:

If график гладкой функции на концах отрезка находится на одинаковой высоте, то на нем обязательно найдется точка, где касательная будет полностью горизонтальной.

Математическое условие:

Если f(a) = f(b), то на интервале существует точка c, в которой производная равна нулю:

f'(c) = 0
