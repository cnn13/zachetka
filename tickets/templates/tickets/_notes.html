Разбор билетов

01 · Понятие предела функции по Коши и по Гейне

Предел функции — число, к которому стремится значение f(x), когда x приближается к точке c.

По Коши: для любого ε > 0 найдётся δ > 0, при котором из 0 < |x − c| < δ следует |f(x) − L| < ε.

По Гейне: значения функции на любой последовательности xₙ → c, xₙ ≠ c стремятся к L.

02 · Теорема Ролля и её геометрический смысл

Если функция непрерывна на [a, b], дифференцируема на (a, b) и f(a) = f(b), существует c ∈ (a, b), где f′(c) = 0.

Геометрически это точка, в которой касательная к графику горизонтальна.

03 · Первый и второй замечательные пределы

Первый: lim (sin x / x) = 1 при x → 0.

Второй: lim (1 + 1/x)ˣ = e при x → ∞.
